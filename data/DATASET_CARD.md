# Dataset card

Primary file: `realistic_multi_organ_diabetes_dataset_4000.csv`

- 4,000 records; 37 columns
- 31 clinical input columns and six binary outcomes
- Synthetic data supplied for coursework and software demonstration
- Not real patient records; not for diagnosis, treatment, or clinical performance claims

The target labels may have been generated from feature rules. Very high held-out scores can therefore reflect synthetic label construction, not real-world model generalization. Statistical network edges are associations, not causal discoveries.
